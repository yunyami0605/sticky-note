# Notion 기능 벤치마크

**작성일:** 2026-11-09  
**목적:** 노션의 주요 기능을 카테고리별로 정리하고, 우리 앱(Sticky Note)에 적용 가능성을 평가한다.

---

## 1. 에디터 핵심 기능

### 1-1. 블록 시스템

| 블록 타입 | 설명 |
|-----------|------|
| 텍스트 | 기본 단락 |
| 헤딩 1/2/3 | H1~H3 제목 |
| 불릿 리스트 | `•` 항목 목록 |
| 번호 리스트 | `1.` 순서 목록 |
| 토글 블록 | 접기/펼치기 가능한 블록 |
| 체크리스트 (To-do) | `[ ]` / `[x]` 체크박스 |
| 인용문 (Quote) | 왼쪽 선이 붙은 블록 |
| 콜아웃 (Callout) | 이모지 아이콘 + 하이라이트 배경 |
| 구분선 (Divider) | `---` 수평선 |
| 코드 블록 | 언어 선택 + 코드 하이라이트 |
| 수식 (Math) | KaTeX 인라인·블록 수식 |
| 테이블 | 행·열 편집 가능한 표 |
| 이미지 | 첨부·URL·드래그 업로드 |
| 파일 첨부 | 임의 파일 |
| 임베드 | URL 미리보기 (YouTube, Figma 등) |
| 북마크 | URL → 카드형 미리보기 |
| 페이지 링크 | 다른 노션 페이지 삽입 |
| 열 레이아웃 (Columns) | 2~5열 나란히 배치 |

### 1-2. 슬래시 커맨드 (`/`)

- 에디터 내 `/` 입력 시 블록 타입 선택 팝업 표시
- 텍스트 검색으로 필터링 가능
- 최근 사용 블록 우선 표시

### 1-3. 인라인 서식

| 서식 | macOS | Windows |
|------|-------|---------|
| 볼드 | `Cmd+B` | `Ctrl+B` |
| 이탤릭 | `Cmd+I` | `Ctrl+I` |
| 밑줄 | `Cmd+U` | `Ctrl+U` |
| 취소선 | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| 인라인 코드 | `Cmd+E` | `Ctrl+E` |
| 텍스트 색상 | 툴바 선택 | 툴바 선택 |
| 배경 색상 | 툴바 선택 | 툴바 선택 |
| 하이퍼링크 | `Cmd+K` | `Ctrl+K` |
| 멘션 (`@`) | 페이지 연결 | 페이지 연결 |

> **멘션 상세**
> - `@페이지명` — 다른 메모/페이지로 이동하는 인라인 링크 삽입
> - 사람 멘션(`@이름`), 날짜 멘션(`@날짜`)은 미적용 → `docs/future-features.md` 참고

> **단축키 커스터마이즈**  
> 사용자가 단축키를 직접 변경할 수 있는 설정 화면 필요. 특히 OS별 기본값 충돌 방지와 한국어 입력 환경(예: `Cmd+B`가 한글 모드에서 오동작) 대응을 위해 중요.

### 1-4. 블록 조작

- **드래그 앤 드롭**: 블록 왼쪽 `⠿` 핸들 드래그로 순서 변경
- **들여쓰기**: `Tab` / `Shift+Tab` 으로 중첩 블록 생성
- **블록 복사·이동**: 블록 메뉴(⋯)에서 복사/다른 페이지로 이동
- **블록 색상 변경**: 블록 단위 텍스트·배경색 적용

## 2. 구조 / 조직화

### 2-1. 페이지 계층 구조

- 페이지 안에 하위 페이지(Sub-page) 무제한 중첩 (UI 기준)
- 사이드바에 트리 형태로 표시
- 페이지 아이콘(이모지·이미지) + 커버 이미지 설정

> **우리 앱 적용 결정:** 무제한 중첩 대신 **폴더 + 페이지 2단계 구조** 채택.  
> 폴더로 메모를 그룹핑하고 사이드바에서 폴더 클릭 시 해당 메모만 필터링. Bear·Apple Notes와 유사한 방식.

### 2-2. 데이터베이스

노션의 핵심 차별점. 페이지 목록을 여러 뷰로 볼 수 있는 구조화된 컬렉션.

**뷰 종류**

| 뷰 | 설명 |
|----|------|
| 테이블 뷰 | 스프레드시트 형태 |
| 보드 뷰 | 칸반 보드 (상태별 그루핑) |
| 갤러리 뷰 | 카드 그리드 |
| 리스트 뷰 | 심플 목록 |
| 캘린더 뷰 | 날짜 속성 기반 월간 보기 |
| 타임라인 뷰 | 간트 차트 형태 |

**속성(Properties) 타입**

텍스트, 숫자, 선택(단일/다중), 날짜, 체크박스, URL, 이메일, 전화번호, 수식, 관계형(Relation), 롤업(Rollup), 생성일, 최종 수정일, 생성자, 최종 수정자

**필터 & 정렬**

- 다중 조건 필터 (AND/OR)
- 다중 정렬 키
- 그루핑 (특정 속성 기준 묶기)

### 2-3. 링크드 데이터베이스 & 뷰

- 같은 데이터베이스를 여러 페이지에서 다른 뷰로 삽입 가능

### 2-4. 즐겨찾기 / 최근 방문

- 사이드바에 즐겨찾기 페이지 고정
- 최근 방문 페이지 목록

### 2-5. 태그 (Multi-select 속성)

- 데이터베이스 속성으로 색상 태그 부여
- 보드 뷰에서 태그별 그루핑 가능

## 6. 우리 앱 적용 가능성 평가

> 범례: ✅ 적합 | 🔶 부분 적용 | ❌ 맞지 않음 (스티키 노트 성격과 충돌)

| 기능 | 적용 가능성 | 메모 |
|------|------------|------|
| 슬래시 커맨드 (`/`) | ✅ | Tiptap에서 구현 가능. 가장 임팩트 큰 UX 개선 |
| 토글 블록 | ✅ | Tiptap Details extension 활용 가능 |
| 콜아웃 블록 | ✅ | 이모지 + 배경색 블록, 메모 가독성 향상 |
| 코드 블록 | ✅ | Tiptap CodeBlock + lowlight |
| 테이블 블록 | 🔶 | 작은 플로팅 창엔 좁을 수 있음 |
| 드래그 앤 드롭 블록 순서 변경 | ✅ | Tiptap DragHandle extension 존재 |
| 태그 시스템 | ✅ | 메모에 색상 태그 추가, 사이드바 필터 |
| 하위 페이지 (중첩 메모) | 🔶 | 플로팅 창 성격과 약간 충돌, 별도 뷰 필요 |
| 데이터베이스 뷰 | 🔶 | 갤러리·리스트 뷰는 사이드바에서 선택 가능 |
| 커버 이미지 / 아이콘 | ✅ | 메모 헤더에 이모지 아이콘 설정 |
| 멘션 (`@`) | ❌ | 단일 사용자 앱, 불필요 |
| 실시간 협업 | ❌ | 로컬 앱 성격과 불일치 |
| 댓글 | ❌ | 개인 메모 도구, 불필요 |
| Notion AI | 🔶 | Claude API 연동으로 요약·번역·초안 가능 |
| 템플릿 | ✅ | 자주 쓰는 메모 구조를 템플릿으로 저장 |
| 변경 이력 | 🔶 | SQLite에 버전 저장 가능하나 용량 고려 필요 |
| 단축키 강화 | ✅ | 현재 Tiptap 기본 단축키만 있음 |
| 임포트/익스포트 | 🔶 | TXT 외 Markdown 임포트·익스포트 추가 가능 |

### 우선순위 추천

1. **슬래시 커맨드** — 가장 노션다운 UX, 구현 난이도 중간
2. **태그 시스템** — 메모 정리에 직접적 도움, DB 변경 필요
3. **토글 블록 + 콜아웃** — 에디터 풍부함, 난이도 낮음
4. **드래그 핸들 (블록 순서 변경)** — Tiptap extension으로 비교적 쉬움
5. **코드 블록** — 개발자 사용자 대상 가치 있음
6. **커버 이미지/아이콘** — 비주얼 개선
7. **Markdown 임포트/익스포트** — TXT보다 범용성 높음
8. **AI 기능 (Claude 연동)** — 중장기 목표

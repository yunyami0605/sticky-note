# ISSUE-015: 사이드바 우클릭 컨텍스트 메뉴 하단 잘림

**상태:** resolved  
**우선순위:** medium  
**유형:** bug  
**생성일:** 2026-11-24  
**수정일:** 2026-11-24  

## 문제 설명

사이드바에서 마우스 우클릭 시 나타나는 플로팅 컨텍스트 메뉴가 하단 혹은 화면 가장자리에 걸릴 경우 잘려서 보임.  
특히 하단에 위치한 폴더나 메모 아이템에서 우클릭 시 메뉴 일부가 화면 밖으로 넘어감.

## 원인 분석

컨텍스트 메뉴 위치 계산 시 뷰포트 경계(하단, 우측) 초과 여부를 체크하지 않고 클릭 좌표 기준으로만 렌더링함.

## 해결 방안

### 추후 개선 (TODO)

- 메뉴 렌더링 전 뷰포트 높이(`window.innerHeight`)와 메뉴 높이를 비교
- 하단 초과 시 클릭 위치 위쪽으로 메뉴를 역방향 표시 (`top` → `bottom` 기준)
- 우측 초과 시 좌측으로 반전

## 해결

`useLayoutEffect`로 렌더 직후 메뉴 실제 높이/너비 측정 → 하단·우측 초과 시 반전.  
`MainPanel/index.tsx` `FolderContextMenu` 컴포넌트 수정.

# ISSUE-006: 중첩 폴더 시각적 구별 어려움

**상태:** closed  
**우선순위:** medium  
**생성일:** 2026-11-17  
**수정일:** 2026-11-17  

## 문제 설명

폴더 안에 하위 폴더가 있을 때 계층 구조가 시각적으로 명확하지 않다.  
`depth * 10px` 들여쓰기만으로는 1~2단계 중첩에서 구별이 힘들다.

## 원인 분석

`TreeSection`의 `marginLeft: depth * 10` 만으로 계층을 표현하고 있고, 추가적인 연결선이나 색상 변화가 없다.

## 해결 방안

### 추후 개선 (TODO)

아래 중 하나 또는 조합:
1. **들여쓰기 가이드 라인** — 하위 폴더 왼쪽에 세로 `1px` 라인 (노션 스타일)
2. **들여쓰기 간격 확대** — `depth * 10` → `depth * 14`
3. **하위 폴더 아이콘 변경** — 최상위 `📁` → 하위 `📂` 또는 더 작은 폴더 아이콘
4. **배경색 단계 적용** — depth가 깊어질수록 미세하게 다른 배경

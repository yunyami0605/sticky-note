**이전 버전:** v1.1 (`planning-v1.1.md`)

## 개요

v1.1 기능이 안정화된 상태에서 검색 고도화, 에디터 미디어 지원, 창 UX 개선, 템플릿을 추가한다.  
기존 스티키 노트 앱의 경량성을 유지하면서 일상 사용성을 높이는 데 집중한다.

> **현재 상태:** 기획 중

## 1. 본문 내용 검색

**현재:** 사이드바 검색창이 메모 제목(첫 줄 텍스트)만 매칭한다.  
**목표:** 메모 본문 전체 텍스트를 대상으로 검색한다.

### 동작 방식

- 검색어 입력 시 제목 + 본문 모두 매칭
- 매칭된 메모 카드에 본문 미리보기에서 **검색어 하이라이트** 표시
- 대소문자 무시, 한/영 모두 지원

### 구현 포인트

- ProseMirror JSON → 텍스트 추출은 기존 `getNoteTitle` 패턴의 `walk` 함수 활용
- 검색은 렌더러 측에서 메모 배열을 필터링 (DB 쿼리 불필요)
- 미리보기 하이라이트: 매칭 위치 앞뒤 ~30자를 잘라 `<mark>` 감싸기

## 2. 메모 이동 UI 개선

**현재:** 드래그 앤 드롭 또는 우클릭 메뉴 → 폴더 선택 없이 미분류로만 이동 가능.  
**목표:** 우클릭 컨텍스트 메뉴에서 "폴더로 이동" 서브메뉴로 대상 폴더를 선택할 수 있도록 한다.

### 동작 방식

- 메모 카드 우클릭 → "폴더로 이동 ▶" 항목
- 호버 시 폴더 목록 서브메뉴 팝업 (미분류 포함)
- 현재 소속 폴더는 체크 표시 또는 비활성화

### 구현 포인트

- `NoteCard` 컨텍스트 메뉴에 서브메뉴 레이어 추가
- 서브메뉴는 Portal 렌더링, 뷰포트 경계 넘을 경우 반전 (ISSUE-015와 동일 패턴)

## 3. 플로팅 창 크기·위치 기억

**현재:** 플로팅 팝업 창은 항상 고정 초기 크기·위치로 열린다.  
**목표:** 메모별로 마지막 창 크기와 위치를 저장해 다음 열 때 복원한다.

### 동작 방식

- 창 이동/리사이즈 완료 시 DB에 `position`, `size` 자동 저장 (디바운스 500ms)
- 메모를 다시 열면 저장된 크기·위치로 복원
- 저장된 위치가 현재 화면 밖이면 화면 중앙으로 fallback

### 구현 포인트

- `position`, `size` 컬럼은 이미 `notes` 테이블에 존재 → 메인 창 에디터가 사용 중인 필드
- 현재 메인 패널은 `position`/`size`를 사용하지 않으므로 플로팅 창 전용으로 활용 가능
- Electron `BrowserWindow` `move` / `resize` 이벤트 → IPC → DB 업데이트

## 4. 에디터 이미지 삽입

**목표:** 에디터 안에 로컬 이미지를 블록으로 삽입한다.

### 동작 방식

- 슬래시 커맨드 `/이미지` → 파일 선택 다이얼로그
- 선택된 이미지는 `{userData}/note-images/` 에 복사 저장
- 에디터 내 `<img>` 블록으로 렌더링 (`file://` URL)
- 이미지 클릭 시 원본 크기로 미리보기 (선택)
- 메모 삭제 시 연결 이미지 파일도 함께 삭제

### 구현 포인트

- Tiptap `Image` extension (`@tiptap/extension-image`) 사용
- JSON에 `file://` 절대 경로 저장
- IPC: `image:add` (파일 복사 + 경로 반환), `image:delete` (파일 삭제)
- 슬래시 커맨드에 `/이미지` 항목 추가

## 5. 템플릿

**목표:** 자주 쓰는 메모 구조를 템플릿으로 저장하고, 새 메모 생성 시 선택해 사용한다.

### 동작 방식

- **저장:** 현재 메모 우클릭 → "템플릿으로 저장" → 이름 입력
- **사용:** 새 메모 생성 버튼 옆 `▾` 클릭 → 템플릿 목록 팝업 → 선택하면 해당 내용으로 메모 생성
- **관리:** 설정 패널 내 "템플릿 관리" 섹션 → 목록 확인 / 삭제

### DB

```sql
CREATE TABLE templates (
  id         TEXT PRIMARY KEY,
  name       TEXT NOT NULL,
  content    TEXT NOT NULL,   -- Tiptap JSON
  created_at TEXT NOT NULL
)
```

### IPC

| 채널 | 설명 |
|------|------|
| `template:getAll` | 전체 템플릿 목록 |
| `template:create` | 템플릿 저장 |
| `template:delete` | 템플릿 삭제 |

## 6. 플로팅 메모 헤더 우클릭 메뉴

**현재:** 플로팅 팝업 헤더(색상 변경·닫기·내려놓기 영역)에 우클릭 기능 없음.  
**목표:** 헤더 우클릭 시 컨텍스트 메뉴를 표시해 빠른 액션을 제공한다.

### 메뉴 항목

| 항목 | 동작 |
|------|------|
| 핀 고정 / 핀 해제 | 창 항상 위 토글 (`isPinned`) |
| 닫기 | 플로팅 창 닫기 |

### 구현 포인트

- `NoteEditor` 헤더 div에 `onContextMenu` 핸들러 추가
- 기존 `FolderContextMenu`와 동일한 Portal + 뷰포트 반전 패턴 사용
- 메뉴 표시 중 헤더 드래그(`WebkitAppRegion: drag`) 비활성화 필요

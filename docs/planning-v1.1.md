**최초 작성:** 2026-11-09 | **최종 수정:** 2026-11-25  
**이전 버전:** v1.0 (`planning-v1.0.md`)

## 개요

v1.0 기반 위에 노션 벤치마크에서 선별한 기능을 추가한다.  
스티키 노트 앱의 가볍고 직관적인 성격을 유지하면서 에디터 풍부함과 메모 조직화를 강화한다.

> **현재 상태:** v1.1 전 Phase 완료. 추가 기능 다수 구현.

## 1. 에디터 블록 확장 ✅

Tiptap StarterKit 기반에서 아래 블록 타입이 추가되었다.

| 블록 | Tiptap Extension | 상태 |
|------|-----------------|------|
| 토글 블록 | `@tiptap/extension-details` | ✅ 완료 |
| 콜아웃 블록 | 커스텀 Node Extension | ✅ 완료 |
| 코드 블록 | `@tiptap/extension-code-block-lowlight` | ✅ 완료 |
| 인용문 (Blockquote) | StarterKit 내장 | ✅ 완료 |
| 구분선 (HorizontalRule) | StarterKit 내장 | ✅ 완료 |
| 테이블 | — | ❌ 미구현 (플로팅 창 공간 제약) |

**콜아웃 블록:**
- 이모지 선택 버튼 (기본값: 💡)
- 블록 배경색: 테마에 따라 연한 회색
- Tiptap 커스텀 Node로 구현

**토글 블록 (개선):**
- `persist: true` — `open` 속성이 ProseMirror 스키마에 등록되어 저장·복원됨
- 생성 시 자동으로 열린 상태 (`open: true`)
- 현재 라인 텍스트를 토글 제목(summary)으로 자동 변환
- Enter 키: 제목에서 → 내용 영역 진입 (Notion 동일), 내용 마지막 빈 줄 → 토글 탈출

## 2. 슬래시 커맨드 (`/`) ✅

에디터 내 `/` 입력 시 블록 타입 선택 팝업 표시.

| 커맨드 | 블록 |
|--------|------|
| `/제목1`, `/h1` | 헤딩 1 |
| `/제목2`, `/h2` | 헤딩 2 |
| `/제목3`, `/h3` | 헤딩 3 |
| `/불릿`, `/ul` | 불릿 목록 |
| `/번호`, `/ol` | 번호 목록 |
| `/체크`, `/todo` | 체크리스트 |
| `/토글` | 토글 블록 |
| `/콜아웃` | 콜아웃 블록 |
| `/코드` | 코드 블록 |
| `/인용` | 인용문 |
| `/구분선`, `/hr` | 구분선 |

**UX:** 텍스트 입력으로 필터링, 키보드 ↑↓ 탐색, Enter 선택, Escape 닫기

## 3. 블록 드래그 핸들 ✅

- 블록 왼쪽 마진 영역에 `⠿` 드래그 핸들 호버 시 표시
- 드래그로 블록 순서 변경 (HTML5 DnD → 마우스 이벤트 기반으로 재구현)
- 파란색 drop indicator 라인으로 삽입 위치 표시
- 에디터 패딩으로 핸들 공간 확보 (글자와 겹치지 않음)

## 4. 폴더 구조 ✅

**구조:**
```
폴더 (Folder)
└── 하위 폴더 (Folder) × N   ← 중첩 무제한
    └── 메모 (Note) × N
```

- 폴더 없는 메모 = "미분류" 섹션에 속함
- 중첩 폴더 지원 (parent_id 기반 트리 구조)
- 폴더 생성 / 이름 변경 / 삭제 / 복제
- 메모를 폴더 간 이동 (우클릭 메뉴, 드래그 앤 드롭)
- 폴더 접기 / 펼치기
- 폴더 드래그로 순서 변경 및 중첩

**사이드바 UI:**
```
┌─────────────────────────────┐
│ [≡▾]              [⚙][✏️][📁] │  헤더 (정렬, 설정, 새메모, 새폴더)
├─────────────────────────────┤
│ 🔍 검색...                  │  검색창
├─────────────────────────────┤
│ ▶ 미분류           (3)      │  폴더 목록
│ ▶ 업무             (5)      │
│   ▶ 하위폴더       (2)      │  중첩 폴더
│ ▶ 개인             (4)      │
├─────────────────────────────┤
│ ● 긴급  ● 업무  ● 완료      │  태그 필터 (하단)
└─────────────────────────────┘
```

**DB:**
```sql
CREATE TABLE folders (
  id        TEXT PRIMARY KEY,
  name      TEXT NOT NULL,
  sort_order INTEGER DEFAULT 0,
  parent_id TEXT,            -- 중첩 폴더 지원
  created_at TEXT NOT NULL
)
ALTER TABLE notes ADD COLUMN folder_id TEXT
```

## 5. 태그 시스템 ✅

- 태그: 이름 + 색상 (8가지 프리셋 색상)
- 메모당 다중 태그 가능
- 사이드바 하단 태그 필터 (클릭 시 해당 태그 메모만 표시)
- 태그 생성 / 삭제
- 메모 카드 하단에 태그 색상 도트 표시

**DB:**
```sql
CREATE TABLE tags (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, color TEXT NOT NULL, created_at TEXT NOT NULL
)
CREATE TABLE note_tags (
  note_id TEXT REFERENCES notes(id) ON DELETE CASCADE,
  tag_id  TEXT REFERENCES tags(id)  ON DELETE CASCADE,
  PRIMARY KEY (note_id, tag_id)
)
```

## 6. 메모 이모지 아이콘 ✅

- 메모별 이모지 아이콘 설정 가능
- 사이드바 메모 카드 및 플로팅 창 헤더에 표시
- 플로팅 창 헤더 클릭 → 네이티브 `prompt()` 로 입력
- DB: `notes` 테이블에 `icon TEXT` 컬럼

## 7. @페이지 멘션 ✅

- 에디터 내 `@` 입력 시 메모 검색 팝업
- 선택 시 해당 메모로 이동하는 인라인 링크 삽입
- 메인 패널: 선택 시 해당 메모로 이동
- 플로팅 창: 선택 시 해당 메모 팝업으로 오픈

## 8. Markdown 임포트 / 익스포트 ✅

**익스포트:**

## 9. 단축키 강화 및 커스터마이즈 ✅

### 9-1. 지원 단축키 (10종)

| 기능 | macOS 기본값 | Windows 기본값 |
|------|------------|--------------|
| 새 메모 | `Cmd+N` | `Ctrl+N` |
| 검색 포커스 | `Cmd+F` | `Ctrl+F` |
| 설정 열기 | `Cmd+,` | `Ctrl+,` |
| 사이드바 토글 | `Cmd+\` | `Ctrl+\` |
| 메모 삭제 | `Cmd+Backspace` | `Ctrl+Backspace` |
| 메모 복제 | `Cmd+D` | `Ctrl+D` |
| 팝업으로 열기 | `Cmd+Enter` | `Ctrl+Enter` |
| 이전 메모 | `Cmd+↑` | `Ctrl+↑` |
| 다음 메모 | `Cmd+↓` | `Ctrl+↓` |
| 테마 전환 | `Cmd+Shift+L` | `Ctrl+Shift+L` |

### 9-2. 커스터마이즈 UI

- 설정 패널 "단축키 설정 열기" 버튼 → 별도 팝업 모달
- 모달: 앱(5종) / 메모(5종) 그룹 분류
- 단축키 버튼 클릭 → **키 입력 서브팝업** (별도 오버레이)
  - 현재 단축키 표시
  - 새 키 입력 후 저장/취소
  - 충돌 감지: 같은 키 조합이 다른 단축키에 이미 등록된 경우 경고 문구 표시, 저장 시 기존 단축키 자동 비움
- 기본값 복원 버튼

## 11. 추가 구현 항목 (계획 외)

v1.1 개발 과정에서 계획에 없던 아래 기능이 추가되었다.

| 기능 | 설명 |
|------|------|
| 중첩 폴더 | 폴더 안에 폴더 무제한 중첩 |
| 메모 양방향 실시간 동기화 | 메인 패널 ↔ 플로팅 창 간 IPC `note:updated` 브로드캐스트 |
| 메모 복제 | 우클릭 메뉴 및 단축키 |
| 다중 선택 삭제 | 사이드바에서 메모 다중 선택 후 일괄 삭제 |
| 폴더 복제 | 폴더 우클릭 → 복제 |
| 편집기 기본 글자 크기 설정 | 설정 패널에서 12~18px 선택, 메인·플로팅 패널 모두 적용 |
| 편집기 기본 글자 색상 설정 | 설정 패널에서 프리셋/커스텀 색상 선택, 메인·플로팅 패널 모두 적용 |
| 메모 패널 글자 배율 50~200% | 하단 `%` 클릭 직접 입력 또는 슬라이더, `Cmd+=` / `Cmd+-` / `Cmd+0` 단축키 지원 |
| 텍스트 선택 인라인 툴바 | 에디터 텍스트 선택 시 서식 버튼(B·I·U·취소선·링크·글자색 등) 팝업 표시 |
| 사이드바 노트 클릭 동작 | 단일 클릭 → 에디터 선택, **더블클릭 → 플로팅 팝업 열기** |
| 신규 메모 N 뱃지 | 내용이 없는 새 메모에 사이드바 카드 우상단 `N` 뱃지 표시 |
| 중첩 폴더 시각 구별 | 들여쓰기 14px + 세로 가이드 라인으로 중첩 깊이 명확히 표시 |
| 툴바 반응형 collapse | 에디터 너비 420px 이하 시 단일 아이콘 버튼으로 전환, 클릭하면 compact 팝업 표시 |
| 전역 정렬 단순화 | 폴더별 개별 정렬 버튼 제거 → 헤더 단일 정렬 아이콘으로 통합, 수동정렬 옵션 제거 |
| 전체 UI 개선 (1차) | NoteCard 레이아웃, 사이드바 헤더, 검색창, 폴더 아이콘, 에디터 빈 상태, 디자인 토큰 |
| 전체 UI 개선 (2차) | 에디터 타이포그래피(line-height 1.72, letter-spacing), 블록 스타일 인디고 통일(blockquote·callout), 툴바 버튼 그룹화(서식/헤딩/목록/블록), active 상태 인디고, NoteCard 콘텐츠 미리보기 1줄 추가, 컨텍스트 메뉴 blur |
| 사이드바 트래픽 라이트 간격 수정 | `titleBarStyle: hiddenInset` 환경에서 버튼 행 위 h-7 스페이서 추가, 패딩 조정 |
| CLAUDE.md 작성 | 아키텍처 맵, 코딩 규칙, IPC 패턴, 드래그 앤 드롭 주의사항, 미구현 항목 문서화 |

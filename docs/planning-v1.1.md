**최초 작성:** 2026-11-09 | **최종 수정:** 2026-11-09  
**이전 버전:** v1.0 (`planning-v1.0.md`)

## 개요

v1.0 기반 위에 노션 벤치마크에서 선별한 기능을 추가한다.  
스티키 노트 앱의 가볍고 직관적인 성격을 유지하면서 에디터 풍부함과 메모 조직화를 강화한다.

---

## 1. 신규 기능 목록

### 1-1. 에디터 블록 확장

현재 Tiptap StarterKit 기반에서 아래 블록 타입을 추가한다.

| 블록 | Tiptap Extension | 우선순위 |
|------|-----------------|---------|
| 토글 블록 | `@tiptap/extension-details` | 높음 |
| 콜아웃 블록 | 커스텀 Node Extension | 높음 |
| 코드 블록 | `@tiptap/extension-code-block-lowlight` | 높음 |
| 인용문 (Blockquote) | StarterKit 내장 (활성화) | 중간 |
| 구분선 (HorizontalRule) | StarterKit 내장 (활성화) | 중간 |
| 테이블 | `@tiptap/extension-table` | 낮음 (플로팅 창 공간 제약) |

#### 콜아웃 블록 스펙

```
[ 이모지 ] 텍스트 내용...
```

- 이모지 선택 버튼 (기본값: 💡)
- 블록 배경색: 테마에 따라 연한 노랑/파랑 등
- Tiptap 커스텀 Node로 구현

### 1-2. 슬래시 커맨드 (`/`)

에디터 내 `/` 입력 시 블록 타입 선택 팝업 표시.

**지원 항목 (우선순위순):**

| 커맨드 | 블록 |
|--------|------|
| `/제목1`, `/h1` | 헤딩 1 |
| `/제목2`, `/h2` | 헤딩 2 |
| `/제목3`, `/h3` | 헤딩 3 |
| `/불릿`, `/ul` | 불릿 목록 |
| `/번호`, `/ol` | 번호 목록 |
| `/체크`, `/todo` | 체크리스트 |
| `/토글` | 토글 블록 |
| `/콜아웃` | 콜아웃 블록 |
| `/코드` | 코드 블록 |
| `/인용` | 인용문 |
| `/구분선`, `/hr` | 구분선 |
| `/테이블` | 테이블 |

**UX:**
- 텍스트 입력으로 필터링
- 키보드 ↑↓ 탐색, Enter 선택, Escape 닫기
- Tiptap `Suggestion` API 활용

### 1-5. 폴더 + 페이지 구조

Bear / Apple Notes 방식의 2단계 구조.

**구조:**
```
폴더 (Folder)
└── 메모 (Note) × N
```

- 폴더 없는 메모 = "미분류" 기본 폴더에 속함
- 사이드바 상단에 폴더 목록 표시, 클릭 시 해당 폴더 메모만 필터링
- 폴더 생성 / 이름 변경 / 삭제
- 메모를 폴더 간 이동 (우클릭 메뉴 또는 드래그)
- 폴더 접기 / 펼치기

**DB 변경:**
```sql
-- folders 테이블 추가
CREATE TABLE folders (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  sortOrder INTEGER DEFAULT 0,
  createdAt TEXT NOT NULL
)

-- notes 테이블에 folderId 컬럼 추가
ALTER TABLE notes ADD COLUMN folderId TEXT REFERENCES folders(id)
```

**사이드바 UI:**
```
┌─────────────────┐
│ [+폴더] [+메모]  │
├─────────────────┤
│ 📁 전체 (12)    │  ← 항상 표시, 모든 메모
│ 📁 미분류 (3)   │
│ 📁 업무 (5)     │  ← 접기/펼치기
│   ▎ 메모 제목   │
│   ▎ 메모 2     │
│ 📁 개인 (4)    │
└─────────────────┘
```

---

### 1-6. 태그 시스템

메모에 색상 태그를 부여하고 사이드바에서 필터링.

**스펙:**
- 태그: 이름 + 색상 (8가지 프리셋 색상)
- 메모당 다중 태그 가능
- 사이드바 하단 또는 별도 태그 패널에서 필터링
- 태그 생성 / 삭제 / 이름 변경

**DB 변경:**
```sql
CREATE TABLE tags (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  color TEXT NOT NULL,  -- hex 색상
  createdAt TEXT NOT NULL
)

CREATE TABLE note_tags (
  noteId TEXT REFERENCES notes(id) ON DELETE CASCADE,
  tagId TEXT REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (noteId, tagId)
)
```

**UI:**
- 메모 카드 하단에 태그 도트 표시
- 사이드바 태그 클릭 시 해당 태그 메모만 필터링

---

### 1-7. 메모 이모지 아이콘

- 메모별 이모지 아이콘 설정 가능
- 사이드바 메모 카드와 플로팅 창 헤더에 표시
- 클릭 시 이모지 피커 팝업 (네이티브 또는 커스텀)
- DB: `notes` 테이블에 `icon TEXT` 컬럼 추가

---

### 1-8. @페이지 멘션

- 에디터 내 `@` 입력 시 메모 검색 팝업
- 선택 시 해당 메모로 이동하는 인라인 링크 삽입
- Tiptap `Suggestion` API (슬래시 커맨드와 동일 메커니즘)

---

### 1-9. Markdown 임포트 / 익스포트

**익스포트:**
- 현재 TXT 외에 `.md` 형식 추가
- Tiptap JSON → Markdown 변환 (`@tiptap/pm` 또는 `prosemirror-markdown`)

**임포트:**
- `.md` 파일을 새 메모로 불러오기
- 설정 패널 내보내기 섹션에 추가

## 2. 변경되는 화면

### 2-1. 사이드바 (폴더 + 태그 추가)

```
┌─────────────────────────────┐
│ [≡▾]  Sticky Note   [⚙][✏️] │  헤더
├─────────────────────────────┤
│ 🔍 검색...            [×]   │  검색
├─────────────────────────────┤
│ 📁 전체            (12)     │  폴더 목록
│ 📁 미분류           (3)     │
│ ▶ 📁 업무           (5)     │  접힘
│ ▼ 📁 개인           (4)     │  펼침
│   🟡 ▎ 메모 제목   10:29   │
│      #태그1 #태그2          │
├─────────────────────────────┤
│ 태그                        │  태그 필터
│ 🔴 긴급  🔵 업무  🟢 완료  │
└─────────────────────────────┘
```

### 2-2. 설정 패널 (단축키 섹션 추가)

```
┌──────────────────────────────┐
│  설정                   [×]  │
├──────────────────────────────┤
│  테마 모드 / 테마 색상        │  (기존)
│  시작 동작                   │  (기존)
│  맞춤법 검사                 │  (기존)
│  ─────────────────────────  │
│  단축키                      │  ← 신규
│  새 메모     [Cmd+N]  [수정] │
│  검색        [Cmd+F]  [수정] │
│  설정        [Cmd+,]  [수정] │
│              [기본값 복원]    │
│  ─────────────────────────  │
│  내보내기                    │  (기존 + MD 추가)
│  [현재 메모 .txt]            │
│  [현재 메모 .md]             │
│  [전체 메모 내보내기]         │
└──────────────────────────────┘
```

│  /                           │  슬래시 커맨드 팝업 활성화
│  ┌──────────────────────┐    │
│  │ 제목1       H1       │    │
│  │ 제목2       H2       │    │

│  │ 토글        ▶        │    │
│  │ 콜아웃      💡       │    │

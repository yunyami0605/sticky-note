## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | Sticky Note (가칭) |
| 목표 | 데스크탑에 항상 떠 있는 가볍고 직관적인 스티커 메모 앱 |

## 3. 기능 목록

### 3.1 노트 관리

- [x] 노트 생성 — 사이드바 상단 아이콘 또는 트레이 메뉴
- [x] 노트 삭제 — 목록 hover 시 × 버튼
- [x] 노트 목록 — 사이드바 세로 목록 (컬러 액센트 바 + 제목 + 날짜)
- [x] 자동 저장 — 입력 멈춤 500ms 후 SQLite에 자동 저장
- [x] 노트 검색 — 사이드바 검색창 (컨텐츠 전문 검색, 클라이언트 필터링)
- [x] 노트 정렬 — 최근 수정순 / 최근 생성순 / 색상별

### 3.2 텍스트 편집

- [x] 기본 서식 — 굵게(B), 기울임(I), 밑줄(U), 취소선(S)
- [x] 헤딩 — H1 / H2
- [x] 리스트 — 불릿 목록, 번호 목록
- [x] 체크리스트 — 할 일(To-do) 체크박스
- [x] 글자 크기 — px 단위 자유 입력 + 프리셋 9종 (8/10/12/14/16/18/20/24/32px)
- [x] 글자 폰트 — 기본 / 고딕 / 명조 / 등폭
- [x] 글자색 — 70가지 팔레트 (10열 × 7행 원형 그리드)
- [x] 글자 배경색 — 70가지 팔레트 (Highlight 확장)

> **기획 대비 변경:** 원래 "폰트 크기 소/중/대 3단계(플로팅 창 전용)" → 양쪽 창 공통 툴바에 px 단위 자유 입력 + 프리셋으로 확장

### 3.3 색상 / 테마

| 위치 | 역할 | 비고 |
|------|------|------|
| **플로팅 노트 창 헤더** | 개별 노트 색상 변경 | 6가지 색상, 즉시 반영 |
| **설정 패널** | 메인 창 전체 테마 변경 | 모드 + 색상 선택 |

- [x] 플로팅 노트 색상 — 노랑, 파랑, 초록, 핑크, 보라, 흰색
- [x] 플로팅 노트 투명도 — 슬라이더 (0.3 ~ 1.0)
- [x] 메인 창 테마 모드 — 다크 / 라이트
- [x] 메인 창 테마 색상 — 각 모드별 6가지 (네이비, 미드나잇, 오션, 포레스트, 로즈, 슬레이트)

### 3.4 데스크탑 통합

- [x] 항상 위 표시 — 플로팅 노트 창 고정 (헤더 초록 버튼 토글)
- [x] 자유 이동 — 플로팅 창 드래그 이동
- [x] 크기 조절 — 플로팅 창 리사이즈
- [x] 시스템 트레이 — 숨기기/보이기/새 메모/종료

### 3.5 설정 패널

- [x] 메인 창 테마 색상 선택 (6가지)
- [x] 다크 / 라이트 모드 토글
- [x] 앱 시작 시 동작 설정 (트레이만 / 메인 창 열기)
- [x] 내보내기 — TXT 현재 메모 / 전체 메모

### 3.6 내보내기

- [x] 현재 메모 TXT 내보내기 — Electron 저장 다이얼로그, Finder/Explorer에서 열기
- [x] 전체 메모 TXT 내보내기 — 폴더 선택 후 메모별 개별 파일 저장
- 내보내기 형식: Tiptap JSON → 평문 텍스트 변환 (헤딩 `#` 마커, 체크리스트 `[x]`/`[ ]` 형식)

**정렬 버튼 (≡▾):** 최근 수정순 / 최근 생성순 / 색상별 드롭다운

### 4.2 플로팅 노트 창

```
┌──────────────────────────────┐
│ ●●●  [🎨🟡🔵🟢🩷🟣⚪]       │  헤더 (드래그 + no-drag 색상 선택)
├──────────────────────────────┤
│  텍스트 에디터                │
├──────────────────────────────┤
│  B I U S | H1 H2 | •≡ 1≡ ☑ │  툴바
│  | 14 기본 [A─] [A▬] |       │  글자크기 · 폰트 · 글자색 · 배경색
├──────────────────────────────┤
│  A↑  ━━━━━━━━━━━━━━━━━━     │  폰트크기(소/중/대) + 투명도
└──────────────────────────────┘
```

> **툴바 글자색/배경색 아이콘:**  
> - 글자색: `A` + 선택색 하단 바  
> - 글자 배경색: 사각 박스 안 `A` + 선택색 하단 바  
> - 팝업: 10열 × 7행 원형 색상 그리드 (Google Sheets 스타일), 재설정 버튼 포함

## 7. 데이터 모델

```typescript
interface Note {
  id: string
  content: string      // Tiptap JSON
  color: NoteColor     // 플로팅 창 노트 색상
  opacity: number      // 0.3 ~ 1.0
  position: { x: number; y: number }
  size: { width: number; height: number }
  isPinned: boolean
  fontSize: 'sm' | 'md' | 'lg'  // 플로팅 창 전용 크기 단계
  createdAt: string
  updatedAt: string
}

interface AppSettings {
  themeMode: 'dark' | 'light'
  themeColor: 'navy' | 'midnight' | 'ocean' | 'forest' | 'rose' | 'slate'
  startBehavior: 'tray' | 'main'
}

// SQLite 테이블: notes, settings (key-value)
```

## 9. 빌드 및 배포

```bash
# 개발 서버
npm run dev

# 빌드 (렌더러 + 메인)
npm run build

# macOS DMG
npm run dist:mac

# Windows NSIS 설치 프로그램
npm run dist:win

# 플랫폼 자동 감지
npm run dist
```

출력 경로: `dist-build/`  
아이콘 파일 필요: `resources/icon.icns` (macOS), `resources/icon.ico` (Windows)

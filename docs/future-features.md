# 추후 기능 목록

**작성일:** 2026-11-09  
**목적:** 현재 범위에서 제외했지만 추후 필요성이 생기면 검토할 기능을 보관한다.

---

## 날짜 멘션 (`@날짜`)

**출처:** 노션 벤치마크 — 인라인 서식 > 멘션  
**내용:** 텍스트 안에 `@오늘`, `@2026-11-09` 같은 날짜를 인라인 태그로 삽입하는 기능.  
노션에서는 해당 날짜에 리마인더 알림을 연결할 수도 있다.

**제외 이유:** 날짜는 직접 타이핑으로 대체 가능. 리마인더까지 구현하려면 OS 알림 연동이 필요해 복잡도 대비 효용이 낮음.

**재검토 조건:** 리마인더·알림 기능 요구가 생길 때. OS 알림 연동(`node-notifier` 또는 Electron `Notification` API)과 함께 묶어서 구현하는 것이 적합.

---

## AI 기능 (Claude 연동)

**출처:** 노션 벤치마크 — AI 기능 (Notion AI)  
**내용:** 노션 AI를 참고한 Claude API 연동 기능.

| 기능 | 설명 |
|------|------|
| 글쓰기 보조 | 선택 텍스트 개선, 톤 변경, 번역 |
| 요약 | 메모 전체 또는 선택 텍스트 요약 |
| 액션 아이템 추출 | 메모 내용 → To-do 자동 추출 |
| 초안 작성 | 프롬프트 기반 텍스트 생성 |
| 자동완성 | 문장 계속 쓰기 |

**제외 이유:** v2 범위 초과. API 키 관리, 비용, 네트워크 의존성 등 고려 사항이 많음.

**재검토 조건:** 핵심 기능이 안정화된 이후. Claude API(`claude-sonnet-4-6`) 연동으로 구현.

## 템플릿

**출처:** 노션 벤치마크 — 기타 UX > 템플릿  
**내용:** 자주 쓰는 메모 구조를 템플릿으로 저장해두고 새 메모 생성 시 선택해서 사용.

**제외 이유:** v1.1 범위 초과. 폴더·에디터 기능이 먼저 안정화되어야 의미 있음.

**재검토 조건:** 사용자 메모 구조가 다양해지고 반복 패턴이 생길 때.

---

## 모바일 앱

**출처:** 노션 벤치마크 — 기타 UX > 모바일 앱  
**내용:** iOS / Android 앱. 오프라인 편집, 위젯 지원.

**제외 이유:** 현재 Electron 데스크탑 앱에 집중. 모바일은 별도 프레임워크(React Native 등) 필요.

**재검토 조건:** 데스크탑 버전이 안정화된 이후 별도 프로젝트로 진행.

---

## API & 외부 연동

**출처:** 노션 벤치마크 — 기타 UX > API & 연동  
**내용:** REST API 제공, Zapier / Slack / GitHub 등 외부 서비스 연동.

**제외 이유:** v1.1 범위 초과. 개인 로컬 앱 단계에서 불필요.

**재검토 조건:** 멀티 디바이스 동기화 또는 팀 사용 요구가 생길 때.
